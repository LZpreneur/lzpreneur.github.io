APP 隱私權政策

本隱私權政策適用於由 LZpreneur OÜ （以下稱「本公司」）開發並發布之所有行動應用程式與 Web App（以下合稱「本應用程式」），包括但不限於：

  • 誰是臥底 Who Is The Spy
  • 有幾堂 Course Kit
  • 以及其他採用相同資料處理架構之應用程式

若您透過第三方平台（例如 Apple App Store、Google Play）下載或付款，請同時參閱該平台之隱私權政策與使用條款。

一、適用範圍

本政策說明本應用程式在您下載、安裝與使用過程中，如何蒐集、使用及保護與您相關的資料。

除本政策另有說明外，本公司不會透過自有伺服器主動蒐集可直接識別您個人身分的資料（例如姓名、電子郵件或電話）。

二、我們蒐集與處理的資料種類

本應用程式依資料最小化原則運作，只蒐集提供核心功能、購買驗證、錯誤排除及廣告投放所必需之有限資料：

2.1 儲存在裝置本機的資料

  • 使用紀錄、設定與內容（例如課程資料、遊戲局資料等）
  • 您所選擇的方案狀態（試用、免費版、買斷版）

上述資料僅儲存在您的裝置本機資料庫（local database），不會上傳至本公司自有伺服器。

當您移除本應用程式時，相關本機資料會一併刪除。

2.2 購買與授權驗證相關資料

為了確認您是否已購買及維持「還原購買」功能正常運作，本應用程式可能透過下列方式處理資訊：

  • 透過 Apple / Google 官方機制，向 App Store / Google Play 傳送平台帳戶之匿名識別資訊（例如 Store 帳號的匿名 ID）、訂單 ID、產品 ID、購買狀態與交易時間，用於核對交易與授權。
  • 在 Cloud Firestore 中僅儲存必要的技術資料，例如：
    • 購買訂單 ID
    • 平台資訊（iOS / Android / Web）
    • 產品 ID 與授權狀態
    • 匿名裝置識別資訊（例如 device ID 或安裝 ID）

本應用程式不會在本公司自有伺服器上建立用戶帳號，也不會將上述識別資訊用於行銷或建立個人檔案。

當您重新安裝或更換裝置時，可透過「還原購買」功能，向 Apple 或 Google 重新驗證購買紀錄以還原授權。

2.3 Firebase 匿名登入（如適用）

部分應用程式為提升系統資安與防止惡意攻擊（如重複購買詐欺或異常使用），可能使用 Firebase Authentication 匿名登入，以便：

  • 建立一個不含姓名、email 等可辨識資訊的匿名使用者 ID
  • 在不同裝置或重新安裝後，安全對應您的購買與使用狀態，避免未授權存取

此匿名 ID 完全由 Google/Firebase 代為生成與管理，本公司不會將其與可直接識別您身分的資訊相結合，亦不會用於行銷或使用者追蹤目的。

2.4 Crashlytics 錯誤與崩潰資訊

為了改善穩定性與除錯，本應用程式可能使用 Firebase Crashlytics 收集下列錯誤相關資訊：

  • 錯誤與崩潰事件的技術紀錄（例如錯誤堆疊、行號）
  • 應用程式版本
  • 裝置型號與作業系統版本

這些資料僅用於分析錯誤與改善產品，不會刻意收集您的輸入內容或應用程式內文稿。

2.5 廣告與第三方廣告識別資訊（AdMob）

若您使用 免費版，本應用程式可能透過 Google AdMob 顯示廣告。為提供與測量廣告服務，AdMob 可能處理以下類型資料：

  • 裝置廣告識別碼（例如 Google Advertising ID / IDFA）
  • 廣告 Cookie、線上識別碼與裝置資訊
  • 基本互動與曝光紀錄，用於廣告投放、成效衡量與防止無效流量

這些資料由 Google 依其隱私權政策與開發者合約處理，不會由本公司用於直接識別您的真實身分。

使用者可參考 Google 的隱私權政策了解更多資訊： 🔗 https://policies.google.com/privacy

三、資料使用目的與 GDPR 法理依據（EEA／英國）

若您位於歐盟／歐洲經濟區（EEA）或英國，本應用程式處理與您相關資料時，將依據 GDPR 之下列法理基礎：

3.1 提供服務及履行契約之必要（GDPR 第 6 條第 1 項 (b) 款）

  • 驗證及維護您的購買與授權狀態
  • 提供應用程式核心功能（含匿名登入與本機設定儲存）
  • 回應您提出的技術支援請求與錯誤排除需求

3.2 合法利益（GDPR 第 6 條第 1 項 (f) 款）

  • 維持應用程式穩定與安全運作
  • 以彙總與匿名／假名化方式分析使用情況，以改善功能與使用者體驗

我們會在合法利益與您的權利與自由間取得合理平衡。

3.3 同意（GDPR 第 6 條第 1 項 (a) 款）

  • 為個人化廣告或進階分析啟用部分 AdMob / AdSense 功能時，將依 Google 及相關法規要求，在必要地區顯示同意提示並取得您的明確 opt‑in 同意。
  • 您可在應用程式內的「隱私設定」或裝置系統設定中調整廣告追蹤偏好，並隨時撤回同意。

如您拒絕或撤回同意，本應用程式仍可能顯示非個人化廣告，或僅使用提供服務所必需的技術性資訊。

四、方案類型與狀態紀錄

本應用程式可能提供以下使用方案：

  • 限時試用：享有全部功能、無廣告
  • 免費版：含廣告顯示、部分功能限制
  • 買斷版：無廣告，解鎖全部功能

您的方案狀態與相關設定僅儲存在裝置本機資料庫內，或以匿名識別方式儲存在 Firebase，用於授權判斷及「還原購買」。本公司不會將此資訊用於建立行銷名單或對外出售。

五、第三方服務與資料處理者

為提供本應用程式的部分功能，我們可能使用由 Google 提供之雲端服務，包括但不限於：

  • Firebase Authentication（匿名登入）
  • Cloud Firestore（儲存訂單 ID、裝置 ID 等有限技術資料）
  • Firebase Crashlytics（錯誤與崩潰報告）
  • Google AdMob / AdSense（廣告投放與成效衡量）

在多數情況下，Google 會依其與我們簽署的《資料處理與安全條款》及歐盟標準合約條款（SCCs）等機制定義為資料處理者（processor），並依其官方隱私權政策與安全文件處理資料。

六、資料保存期間

  • 匿名登入與購買驗證資料：於維持授權辨識及還原購買所必要期間內保存；當不再需要，將刪除或依技術可行性採匿名／假名化處理。
  • Crashlytics 錯誤紀錄：一般僅於 Google / Firebase 預設或必要之有限期間內保存，用於錯誤分析與穩定性改善，之後將刪除或匿名化。
  • 廣告相關資料：由 Google 依其隱私權與保留政策處理，並依適用法律要求在一定期間後進行刪除或彙總／匿名化。

七、您的權利（GDPR／其他適用法律）

在適用法律範圍內，您可能享有以下權利：

  • 查詢與存取：瞭解我們是否處理與您相關之資料及其內容（在可合理識別範圍內）。
  • 更正：要求更正不正確或不完整的資料。
  • 刪除：在不再需要且無法定義務保存時，要求刪除相關資料。
  • 限制處理：在特定情況下，要求暫時限制處理。
  • 資料可攜：在符合法定條件時，要求以結構化、通用且機器可讀格式取得資料。
  • 反對：就基於合法利益之處理提出反對（在適用範圍內）。
  • 撤回同意：對於基於您同意之處理，您可隨時撤回，不影響撤回前之合法性。

請注意，若您要求刪除或限制處理與「購買驗證」相關資料，可能會影響我們提供還原購買或權益確認之能力。

如欲行使上述權利，請依「聯絡我們」章節提供之方式與本公司聯繫，我們將於合理期間內依適用法令處理。

八、國際資料傳輸與安全

與 Firebase、AdMob 等第三方服務相關之資料，可能於歐盟／EEA 以外（例如 Google 伺服器所在地）處理與儲存。

在涉及跨境傳輸時，我們將依 GDPR 及其他相關法令，透過標準合約條款（SCCs）等適當保障措施，合理保護您的資料安全與權益。

本公司亦採取適當的技術與組織性措施保護資料，包括：

  • 使用 HTTPS 加密傳輸與安全連線
  • 嚴格權限控管與 API 金鑰管理
  • 依「最小必要權限」原則進行存取設定並定期檢視

九、兒童資料

除非另有明確說明，本應用程式並非針對 16 歲以下兒童設計，亦不會明知地蒐集 16 歲以下兒童之個人資料。

如您為法定代理人並認為本應用程式不當蒐集兒童資料，請與本公司聯繫，我們將依適用法令採取合理措施刪除。

十、聯絡我們

若您對本應用程式的隱私權或資料保護有任何疑問、要求或投訴，請聯絡：

  • 電子郵件：support@lzpreneur.io

若您居住於歐盟／EEA 或英國，且對我們處理您個人資料的方式有疑慮，您亦有權向當地資料保護主管機關提出申訴。

十一、政策更新

本公司得因服務調整、技術更新或法規變更，不時修訂本隱私權政策。

最新版本將公布於本頁或應用程式內相應位置，並標示生效日期。您於政策更新後持續使用本應用程式，即視為您已閱讀、瞭解並同意受更新後條款之約束。
