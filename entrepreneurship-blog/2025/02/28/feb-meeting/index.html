第一個月會議集

February 28, 2025 · 5 min read
Lucy
Co-Founder of SAD-AI

創業的第一場會議，很快的決定好幾件事

我們創業進行的分工和方式，先簡單說明。

分工​

Zane 本身是技術狂熱者，對技術有著滿腔熱血和工程師魂，當仁不讓的負責技術架構和規劃。

各種技術知識和新知，都逃不過他的知識探索雷達。有時他會扮演關鍵的角色，冷靜的分析和判斷。

如果我猶豫不決的時候，更會大膽的下決策，然後一起承擔 😆。


Lucy 主要處理任何管理、組織、行銷、文案撰寫、專案管理、溝通的事務，本身也是前端工程師。

跟隨著 Zane 學習技術，是走串套件派，會用會串，遇到問題時，會馬上找出解決方案。


如果論技術 1 ~ 10 分，筆者算是 6；Zane 是 9。

如果論管理 1 ~ 10 分，筆者算是 9；Zane 是 6。


也因此有了這樣的分工，我們各有專長，學習分工合作，一起達成目標。🥸

Zane 開發主要框架，筆者則是著框架走，一邊作筆記一邊開發。

開會方式​

我們是固定每週一次，討論項目比較多，就會多安排一次。

每次開會固定 2 ~ 2.5 小時，一週一個 Sprint。

開會主要討論當週執行的任務，開會前準備的內容，也會在會議中決定出解決方案。

不浪費任何寶貴的時間，因為我們各自還有其他生活重心要顧。

創業固然是我們想在人生中嘗試的夢想清單之一，但也不會忽略其他在我們生活中寶貴的人事物。

所以會議集中火力，討論、決議、反思，快刀斬亂馬的進行會議重點！

20250218​

第一場會議，會議前我已經先整理好開會要決議的項目，例如：

  • domain
  • 官網內容
  • 產品 MVP feature
  • 時程規劃

我們兩個遇到沒什麼想法時，都是屬於選擇障礙的類型

這天會議花最多時間是，決定 domain 名稱

因為原本的名稱，已經被買走了，於是我們列了幾種排列組合，

還要考量 SEO 的情況下，實在不知道哪個好。

找合適 domain 前後花了約 30 分鐘，算是有點久，遲遲沒有定案， 都讓我們感到無所適從。

於是我們用了刪去法，留下三個合適的名字，


接著！用 轉輪盤決定 都被我們轉中的名字，就買那組 domain ! 😊

省去了我們很多精力 😅


其他項目，也很順利討論出適合的作法。這天的心得是

猶豫不決的時候，就交給轉盤吧！

20250225​

這天討論：

  • UI Mockup
  • 轉移初代官網到新帳號
  • 決議專案管理工具
  • Review MVP feature 可行性評估
  • 建立 Discord 頻道
  • 暫定產品 Logo

由於我們平時都很忙，一個忙著照顧家人考證照，一個忙著運動和打理生活。

這天會議，Zane 很快速的就把 github repo 和 github action 處理到一個段落。


接著，我們討論原先使用的 ClickUp是否改以 JIRA, Confluence 來管理專案。

最後考量熟悉度、畫面可讀、費用，還是棄用 ClickUp。

因為時間對我們來說，最珍貴。能先將專案往前進行最重要。

20250227​

討論：

  • 當週 Sprint 要完成的任務
  • 繼續調整產品官網的 CI/CD
  • 調整 Discord 頻道命名方式，權限調整
  • 盤點 Survey 的語言框架

這天會議約 2 小時不到，很快速的把該列的項目列清楚。 接著就是執行完成。

決定好的選擇，不用回頭想對不對，讓它變成對的，就是了！
